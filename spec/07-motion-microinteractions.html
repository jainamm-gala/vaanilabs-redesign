Reference mock for spec/07-motion-microinteractions.md (Sutradhar). Every value comes from spec/tokens/tokens.css; the four proposed tokens (--dur-spin, --live-pulse-cycles, --shift-sheet, --timing-skeleton-min) and the [data-motion="reduce"] block are mirrored in this file until they ship. Static frames show each moment; the demo buttons run the real timings. All flows, leads and numbers are fictional.

Add ?theme=dark or ?motion=reduce to the URL for renders.

1 · Tokens and the motion budget

Spec §2 · F §11 · F-A11Y-022

Three durations and one easing do all the work. Everything enters with its own duration and leaves in 90 ms. Nothing in the app runs longer than 200 ms except the 480 ms test trace and the live pulse, which stops after three cycles. Pointer-driven motion (drag, pan, scrub) is never eased.

Timing chart · 0 to 600 ms · one easing, cubic-bezier(0.2, 0, 0, 1)
--ease-standard · fast start, long settle

Grey line: linear, used only for the spinner and the indeterminate bar. No springs, no overshoot.

The only loops · live pulse ×3 per entry into Live, then solid · a spinner only while a request is pending · meters only on real audio

5 · Flow Designer: drag, snap, connect, test trace

Spec §10, §11 · F-FLOW-011, F-FLOW-021, F-FLOW-016, F-FLOW-025, F-A11Y-001, F-A11Y-007

Edges never animate at rest. A dragged step follows the pointer exactly, holds on alignment guides, and settles onto the 16 px grid when released (hold Alt to place freely, Esc to cancel). Dragging from the free "Later" socket connects it: valid input ports grow and the ghost snaps to them. Run test step walks a text test: the current step gets Now at once, and the edge just taken is drawn once in 480 ms.

6 · Live calls: state changes and audio meters

Spec §12 · MD3 · F-VIS-029, F-UX-026, F-A11Y-022, F-A11Y-014, F-QA-037

Every state change happens in one frame, with a 90 ms tone repaint and a debounced announcement. Ringing never animates; the ring is audio. Entering Live starts the only pulse in the product, for three cycles (4.8 s), then the dot holds. Meters light bars from real audio and never change size; with reduced motion a word replaces them.

7 · What must not animate

Spec §14 · 36 keyframes become 9

Each card is something the product does today or a common template habit, and what replaces it. The compiled CSS may contain only the nine vl-* keyframes.

Idle rings and orbs

The 320 px STANDBY ring, orb and breathing "Awaiting connection…" on the idle Cockpit.

Instead · a static Ready-to-call card; motion only on real call state.

Marching-ants edges

25 of 27 flow edges animate forever, even with reduced motion.

Instead · static edges; one 480 ms trace on the edge a test takes.

Skeleton shimmer

A sweeping highlight that says "busy" while nothing changes.

Instead · static bars after 200 ms, kept 400 ms, and a hidden "Loading leads…".

Hover lift and glow

Primary buttons rise 1 px and glow 20 px blue on hover.

Instead · a 90 ms fill change; no shadow, scale or translate.

Counting numbers, growing bars

KPIs that count up, chart bars that grow, balances that roll.

Instead · values appear in one frame.

Typing transcripts

Typewriter carets and per-word fades on agent speech.

Instead · a partial turn in text-3 ending "…", replaced by the final text.

Page transitions

Fades or slides between routes; scroll reveals.

Instead · one-frame render; RouteProgress only when slow.

Error and success theatre

Shaking fields, red flashes, confetti, checks that draw themselves.

Instead · the message where it applies; StatusText or a toast.

Ringing effects

Pulsing call cards, shaking phone icons, blinking tab titles.

Instead · "Ringing… 00:03", the stepper and the audio.

Logo and ticker loops

The looping logo, the random "22ms" and "SYS: ONLINE" ticker.

Instead · a static mark; line quality only during a call.

Height and width animation

Accordions, docked sheets or the sidebar animating their size.

Instead · layout changes in one frame; only chevrons rotate.

Countdown bars and rings

Shrinking bars on toasts, a spinning UPI expiry ring.

Instead · "Expires in 4:12" as text; toasts pause on hover.

8 · Reduced motion

Spec §13 · MD4 · F-A11Y-022

Two sources, one behaviour: the OS setting and the account menu's "Motion: Reduce motion". Nothing travels; short fades stay because they are state changes; every state keeps its word, icon or mark. Use the switch at the top of this page to feel the difference in every demo.
