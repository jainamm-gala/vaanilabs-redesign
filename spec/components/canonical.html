Canonical components

The one reference render for every signature component. Nothing on this page restyles a component: the markup uses the classes of components.css and the page adds layout only (cn- classes). Every other mock links the same file, and node spec/components/check-mocks.mjs fails if a mock redefines a component or uses a colour that is not a token.

Each section below is one PNG in spec/components/canonical/; 00-design-direction.md §8.1 maps them. Sample data only; no real customers.

Button and IconButton

One Button with five variants and three sizes; the default is secondary. One primary per region. Disabled always carries a visible reason (02-components-core §2).
