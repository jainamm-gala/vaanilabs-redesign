Core controls, every state, both themes

Each panel renders the same markup twice: on the left inside data-theme="light", on the right inside data-theme="dark". Hover, pressed and focus states are frozen with review classes so they can be compared. The CSS in this file is the reference for components/ui and uses only tokens from ../tokens/tokens.css.

Sample data only. Flow names are the template gallery's; numbers are masked or the documented example 98765 43210.

Buttons

One Button with five variants and three sizes. One primary per region; disabled always says why; labels never wrap.

Field anatomy and text inputs

A real label, a hint or error below, a count when there is a limit. One field box for every input; the box draws the focus outline.

Spec §3 · F-A11Y-003, F-A11Y-020, F-VIS-018, F-VIS-019, F-A11Y-025

Phone (+91) and money (INR)

Paste any Indian format, store E.164, show the example in the hint. Rupee amounts state their bounds, never clamp, and the Pay button names the amount.

Spec §4 · F-QA-020, F-QA-021, F-UX-021, F-UX-025

Select, Combobox, FlowSwitcher, MultiSelect

One listbox popover. The FlowSwitcher names the live version, disambiguates duplicates and keeps New flow visible.

Spec §5 · F-VIS-037, F-UX-005, F-FLOW-012, F-A11Y-016

Checkbox, Radio, Switch, SegmentedControl

Checked marks use the Neel fill with an accent-mark edge; focus sits on the visible box; switches report saving and failure.

Spec §6 · F-A11Y-006, F-A11Y-016, F-UX-012, F-UX-014, F-RWD-006

Slider

A machined thumb, the value as text, a recommended mark, and a paired number field for exact values.

Spec §6.5 · F-FLOW-032
